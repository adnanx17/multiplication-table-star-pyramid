# Multiplication Table & Star Pyramid

This is a beginner-level C++ program that demonstrates:

- Multiplication table generation
- Star pyramid pattern
- Nested loops
- Basic input validation

## Features

### Multiplication Table
The program takes a number as input and prints its multiplication table.

### Star Pyramid
The program takes the height of the pyramid and prints a centered star pyramid.

## Technologies Used

- C++
- Loops
- Conditional statements
- Basic input/output
